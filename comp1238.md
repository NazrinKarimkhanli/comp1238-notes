# COMP1238 Notes

## Week 1 - History
- One writing system can be used by many languages.
- Cuneiform is an early writing system.

## Week 2 - Bits and Bytes
- A bit is the smallest unit of data in a computer.
- Eight bits make one byte.

## Week 3 - Markup Languages
- Text files use punctuation, whitespace, and line breaks to organize text.
- Markdown and HTML are markup languages. JSON and XML are structured data formats.
- Special characters and escaping are important topics in text files.

## Week 4 - Keyboards and Editors
- Touch typing and keyboard shortcuts help us work with a keyboard.
- Notepad and VS Code are text editors.
- Wildcards and regular expressions (regex) are used when searching in text.
- VS Code Online can be used through GitHub.

## Week 5 - Command Line Interface (CLI)
- CLI means Command Line Interface. We learn about its history and value.
- A terminal and a shell are topics related to using command-line tools.
- SSH is used for remote access.
- SFTP and SCP are used to transfer files.
